    type: paragraph

        type: text
        text: "I didn't want to hand my understanding over to an agent. With v4, that's exactly what I did, and it's the first time I finished. In previous attempts, I had agents build too big of a swath at once. This time I started by building the initial screens with no real data to get a sense of how Native Components were structured. Once I got the pages to a good starting place, I started adding a Saloon integration with the existing web app's API (leftover from previous attempts). From there I went into connecting the pieces and iterating. Each time I sat down to work I asked an agent to work on a small piece, and tested it on my phone or in the simulator, looked over the code, asked questions that I had about the code and asked the agent to fix any bugs I found.
